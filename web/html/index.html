Teasi maps from OpenStreetMap

Maps for the Teasi PRO bike navigator, one zip per country or region: street map, address search, POIs, routing and elevation.

How to install

  1. Connect the Teasi by USB and confirm the connection on its display.
  2. Unzip the download and copy every *.v2026… file into BikeNav/Map/Countries/.
  3. Delete an older map of the same country first, or the device may keep using it. For Denmark, Germany, Norway and Sweden the original maps are also listed in BikeNav/packages.xml: without fixing those entries the Teasi warns “Karten nicht korrekt installiert” at startup (the map works anyway).

Easier: the installer does all of this from Chrome or Edge — choose the Teasi drive, pick a map, done.

The maps run on devices from the 19 production batches (2013–2019) that share the built-in key, i.e. whose serial number starts with one of 20130125 20130212 20130213 20130807 20131010 20131020 20131026 20150215 20160505 20160509 20161014 20161028 20170606 20170707 20180914 20181225 20190320 20190415 20190618, and only for countries the device is licensed for. Each zip has a README with details and checksums. Downloads are capped at 10 Mbit/s in total, so a big country takes a while.
