Teasi map installer

Puts a map from OpenStreetMap onto a Teasi PRO straight from the browser: it deletes the old map of that country, writes the new files while they download, and fixes the entries in BikeNav/packages.xml so the device does not complain at startup.

This browser cannot write to a drive. Use Chrome, Edge or another Chromium-based browser on a computer (not on a phone).

1. Connect the Teasi

Connect it by USB, confirm the connection on its display, then choose the Teasi drive (or its BikeNav folder) and allow editing.

Downloads share 10 Mbit/s, so a big country takes a while (Germany, 1.5 GB: about 20 minutes). Keep this tab open and in front until it says done (then the computer does not go to sleep, but closing the lid still sends it). If the connection breaks or the computer sleeps, it goes on by itself once it is back; if the tab was closed, choose the same map again and it goes on with the next file. Then eject the drive before you unplug the Teasi. Map data © OpenStreetMap contributors, ODbL 1.0; elevation Copernicus DEM GLO-90. Not affiliated with the maker of the Teasi.
